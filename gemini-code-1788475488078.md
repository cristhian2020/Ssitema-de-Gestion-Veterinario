Actúa como un arquitecto de software y desarrollador Fullstack senior especializado en Next.js, bases de datos relacionales y TypeScript.

Diseña y genera la arquitectura y el código base para una aplicación de gestión clínica y reservas para una Veterinaria llamada "[Nombre de la Veterinaria]".

Stack Tecnológico Requerido:
- Framework: Next.js (App Router, Server Actions, Server Components).
- Lenguaje: TypeScript.
- Base de datos: Neon (PostgreSQL Serverless).
- ORM: Drizzle ORM (optimizado para entornos serverless y type-safety).
- Estilos & UI: Tailwind CSS + componentes basados en Radix UI / Shadcn UI + Lucide Icons.
- Autenticación: Sistema de roles (Admin, Veterinario, Recepcionista, Cliente/Dueño).

Módulos y Funcionalidades Clave:

1. Gestión de Mascotas y Propietarios:
   - CRUD de clientes (dueños) con contacto directo vía WhatsApp y correo.
   - Perfil de cada mascota: Nombre, especie, raza, peso, fecha de nacimiento, foto, historial de alergias y chip identificador.

2. Historial Clínico Digital:
   - Registro de consultas, diagnósticos, recetas médicas en PDF y notas veterinarias.
   - Calendario de vacunación y desparasitación con estado (Pendiente, Aplicada, Vencida).

3. Sistema de Citas y Reservas:
   - Calendario interactivo para recepción y veterinarios (agendamiento por horas disponibles).
   - Tipos de cita: Consulta general, Vacunación, Cirugía, Urgencias, Peluquería/Estética.
   - Recordatorio automático con enlace directo a mensaje de WhatsApp para confirmación.

4. Control de Inventario Básico & Servicios:
   - Registro de medicamentos, vacunas y alimentos con stock mínimo y alertas.
   - Catálogo de servicios y precios asociados para facturación/cobro rápido.

5. Portal Público / Landing de Reservas (Cliente final):
   - Formulario sencillo para que los dueños soliciten citas online sin fricción.
   - Botón directo para emergencias 24/7 por WhatsApp.

Requisitos de Entrega:

1. Esquema de Base de Datos (Drizzle Schema):
   - Tablas relacionales normalizadas: `users`, `owners`, `pets`, `appointments`, `medical_records`, `vaccines`, `services`.
   - Índices y claves foráneas correctas.

2. Configuración de Conexión:
   - Archivo de conexión a Neon con `@neondatabase/serverless` y Drizzle.

3. Server Actions & Mutaciones:
   - Ejemplos de acciones seguras con validación mediante `zod` para:
     * Registrar una nueva mascota asociada a un dueño.
     * Agendar una nueva cita verificando disponibilidad horaria.
     * Agregar una entrada al historial médico.

4. Componentes UI (Dashboard & Vistas):
   - Layout del Dashboard con barra lateral (Sidebar) responsiva.
   - Vista de calendario/lista de citas diarias con estados (Pendiente, En Consulta, Finalizada, Cancelada).
   - Componente de formulario modal con validaciones y feedback visual (Toasts).

El código debe ser modular, tipado estrictamente, limpio y listo para producción, siguiendo las mejores prácticas del App Router de Next.js.
